# CentGPT Public

This repository hosts the public **CentGPT FREE** web edition.

The protected master source, extended prompt database, PRO logic, private templates, and future paid features are maintained separately in a private repository.

## Public deployment
GitHub Pages publishes the contents of `cent-commander/`.

## Security model
Do not place secrets, private prompt databases, licensing logic, API keys, or paid-only content in this public repository.
